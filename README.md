# CodeAlpha_HangmanGame

Task 1 of the **CodeAlpha Python Programming Internship**.

A simple text-based Hangman game where the player guesses a word one letter at a time.

## Features
- Random word chosen from a list of 5 predefined words
- Maximum of 6 incorrect guesses
- ASCII hangman drawing that updates with each wrong guess
- Input validation (single letters only, no repeated guesses)
- Option to play again

## Concepts Used
`random`, `while` loops, `if-else`, strings, lists, sets, functions

## How to Run
```bash
python hangman.py
```
Requires Python 3.6+. No external libraries needed.
